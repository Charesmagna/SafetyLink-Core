# SafetyLink Org Console

Windows desktop application for organisations to monitor their SafetyLink users in real-time.

## Features
- Real-time user tracking via live map
- SOS alert notifications
- Incident log
- User status dashboard

## Login
Use your **Organisation ID** (from the SafetyLink mobile app) + your admin email and password.

## Build
```bash
npm install
npm run electron:build
```
